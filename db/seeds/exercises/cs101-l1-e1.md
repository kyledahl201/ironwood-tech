# Variables and reassignment

## Prompt
Create a variable `price` set to 10. Then add 5 to it by reassigning `price` (don't just write 15). Create `count` set to 3. Print `price * count`.

## Starter code
```ruby
price = 10
# reassign price here

count = 3
# print price times count
```

## Checks
| type | call / input | expected |
|---|---|---|
| stdout | - | `45\n` |
| source_matches | - | regex `price\s*(=\s*price\s*\+\|\+=)\s*5` (reassignment, not a literal 15) |

## Hints (shown one at a time, only after a failed check)
1. Reassigning means using the old value on the right side: `name = name + something`.
2. Ruby also has a shortcut: `price += 5` does the same thing.
3. Print with `puts` and an expression: `puts a * b`.
