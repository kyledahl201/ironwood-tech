# Only the big ones

## Prompt
Write `sum_over(numbers, limit)` that returns the total of only the numbers **greater than** `limit`. Use `.each` and `if`. Then print `sum_over([4, 7, 2], 3)`.

## Starter code
```ruby
def sum_over(numbers, limit)
  total = 0
  # your loop here
  total
end

# print sum_over([4, 7, 2], 3)
```

## Checks
| type | call / input | expected |
|---|---|---|
| method_returns | `sum_over([4, 7, 2], 3)` | `11` |
| method_returns | `sum_over([1, 2, 3], 5)` | `0` |
| method_returns | `sum_over([5, 5, 6], 5)` | `6` |
| stdout | - | `11\n` |

## Hints (shown one at a time, only after a failed check)
1. Start from your `sum_list` and add a test before adding.
2. `if n > limit` ... `end` goes inside the loop, around the line that adds.
3. Greater than means `>`, not `>=`. Check the `[5, 5, 6]` case: only 6 counts.
