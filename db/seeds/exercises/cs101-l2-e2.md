# Find the bug: nil from puts

## Prompt
This method is supposed to return a greeting so other code can use it, but the program crashes with `undefined method 'upcase' for nil`. Fix `greeting` so it **returns** the string instead of printing it. Do not change the last two lines.

## Starter code
```ruby
def greeting(name)
  puts "Hello, #{name}"
end

shout = greeting("Kyle").upcase
puts shout
```

## Checks
| type | call / input | expected |
|---|---|---|
| method_returns | `greeting("Kyle")` | `"Hello, Kyle"` |
| method_stdout_empty | `greeting("Kyle")` | greeting prints nothing |
| stdout | - | `HELLO, KYLE\n` |

## Hints (shown one at a time, only after a failed check)
1. What does `puts` return? Try `x = puts "hi"` and then `p x`.
2. `puts` returns `nil`, and `nil` has no `upcase`. The method needs to end with the string itself.
3. Remove `puts` from inside the method and leave just the string as the last line.
