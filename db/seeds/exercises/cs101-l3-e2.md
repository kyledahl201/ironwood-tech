# Loop with .each

## Prompt
Given `scores = [70, 85, 92]`, use `.each` to print every score on its own line, with the word `Score:` in front.

Expected:
```
Score: 70
Score: 85
Score: 92
```

## Starter code
```ruby
scores = [70, 85, 92]

# use scores.each here
```

## Checks
| type | call / input | expected |
|---|---|---|
| stdout | - | `Score: 70\nScore: 85\nScore: 92\n` |
| source_includes | - | .each |

## Hints (shown one at a time, only after a failed check)
1. The shape is `scores.each do |score| ... end`. The name between the bars is yours to pick.
2. Inside the block, `score` holds one number at a time.
3. Put a number inside a string with interpolation: `"Score: #{score}"`.
