# puts shows, return hands back

## Prompt
Write a method `double(n)` that **returns** twice `n`. It must not print anything. Then, outside the method, print the result of `double(21)`.

## Starter code
```ruby
def double(n)
  # return twice n, do not puts here
end

# print double(21) here
```

## Checks
| type | call / input | expected |
|---|---|---|
| method_returns | `double(21)` | `42` |
| method_returns | `double(0)` | `0` |
| method_stdout_empty | `double(5)` | calling double prints nothing |
| stdout | - | `42\n` |

## Hints (shown one at a time, only after a failed check)
1. Inside the method, the value of the last line is what gets returned. `puts` inside the method would print, but then the method returns `nil`.
2. The method body can be one line: `n * 2`. You can also write `return n * 2`.
3. The printing belongs outside the method: `puts double(21)`.
