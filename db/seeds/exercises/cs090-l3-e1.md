# Your first program

## Prompt
Write a program that prints exactly two lines:

```
Hello, Ironwood!
Day 1 of my CS journey.
```

## Starter code
```ruby
# Print two lines below.
```

## Checks
| type | call / input | expected |
|---|---|---|
| stdout | - | `Hello, Ironwood!\nDay 1 of my CS journey.\n` |

## Hints (shown one at a time, only after a failed check)
1. Each line needs its own `puts`.
2. Text goes inside quotes: `puts "some text"`.
3. Check spelling, the comma, the exclamation mark and the period. The checker compares every character.
