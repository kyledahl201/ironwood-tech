## Step: teach
Last class you installed a modern Ruby. Today you'll learn to move around your computer from the Terminal, make folders and files, and write your first Ruby program that lives in a **file** instead of a one-liner.

Every developer does this dozens of times a day. By the end, you'll have a `~/code/ironwood` folder that holds all your CS 090 work.

## Step: teach
Think of your folders as rooms. `pwd` tells you which room you're in, and `ls` shows what's in it. `cd` (change directory) walks you into another room.

- `cd code` goes into the folder called `code` inside the room you're in.
- `cd ..` goes up one level, back to the room that holds this one.
- `cd ~` or just `cd` takes you home from anywhere.

## Step: teach
Folders hold files. `touch name` creates an empty file. `cat name` prints what's inside a file. You already know `echo "text" > name` from last homework, and it writes text into a file.

Files that end in `.rb` are Ruby programs. The ending (the "extension") is a label that tells you and your tools what kind of file it is.

## Step: try
mode: terminal
Create an empty file named `hello.rb` in `~/code/ironwood`, then list the folder to see it.

### Checks
| type | call / input | expected |
|---|---|---|
| file_exists | - | ~/code/ironwood/hello.rb |
| command_matches | - | `^ls` |

### Hints
1. One command creates an empty file. It's named after what your finger does to a screen.
2. `touch hello.rb`, then `ls`.

## Step: try
mode: terminal
Put one line of Ruby into `hello.rb` so that it prints `Hello from a file`. Use `echo` with `>`. Then show the file with `cat`.

### Checks
| type | call / input | expected |
|---|---|---|
| file_contains | ~/code/ironwood/hello.rb | puts |
| file_contains | ~/code/ironwood/hello.rb | Hello from a file |
| command_matches | - | `^cat\s+hello\.rb$` |

### Hints
1. The Ruby line you want is the same `puts` you used in Lesson 1, without the `ruby -e` part.
2. The Ruby line has double quotes inside it. Wrap the whole thing for `echo` in **single** quotes so the two kinds don't clash. This is last lesson's judge-it bug.
3. Shape: `echo '...' > hello.rb`, then `cat hello.rb`.

## Step: try
mode: terminal
Now run it as a program.

### Checks
| type | call / input | expected |
|---|---|---|
| command_matches | - | `^ruby\s+hello\.rb$` |
| output_matches | - | `^Hello from a file$` |

### Hints
1. `ruby` followed by the file's name.
2. You must be standing in the folder that holds the file. Check with `pwd` if it can't find it.

## Step: quiz

- [ ] There is none
- [x] `-e` runs code you type on the line; `ruby hello.rb` runs the code saved in a file

## Step: quiz

- [ ] Ruby is broken

## Step: teach
That's CS 090's toolbox: Terminal, folders, files, an editor and a modern Ruby. From now on, every program you write lives in a file inside `~/code`.

One habit to start now: **after every change, save, run, and read the output**. Small loops catch small mistakes. Study guide, flashcards and homework are below, and finishing this lesson unlocks your first Code Lab exercise.

## Study guide
- `cd folder` moves into a folder, `cd ..` moves up one, and `cd` alone goes home.
- `mkdir name` makes a folder. `mkdir -p` makes parent folders too and doesn't complain if it exists.
- `touch name` makes an empty file, and `cat name` prints a file.
- `.rb` files are Ruby programs. Run one with `ruby file.rb` from the folder it's in.
- When text has double quotes inside it, wrap it in single quotes for the shell.
- `code .` opens the current folder in VS Code.
- Ruby runs the saved file. Save, run, read the output, every time.

## Flashcards
- What does `cd ..` do? :: Moves you up one folder.
- What does `cd` with nothing after it do? :: Takes you to your home folder.
- How do you make a folder? :: `mkdir name`
- How do you make an empty file? :: `touch name`
- How do you print what's in a file? :: `cat name`
- How do you run a Ruby file? :: `ruby file.rb`, from the folder that holds it.
- What does the `.` in `code .` mean? :: This folder, the one you're standing in.
- Why might your program print old output? :: The file wasn't saved.
