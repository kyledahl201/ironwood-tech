## Step: teach
Welcome back, Kyle. Last time you met the Terminal and ran your first program with the Ruby that came with your Mac. Today we install **your own** tools, so you never have to touch Apple's copy again.

Two tools do the work. **Homebrew** installs other programs for you. **mise** installs and switches between versions of languages like Ruby. By the end of class, `ruby -v` will show a modern version.

## Step: teach
Before we install anything, a little Terminal practice. The workbench below is a **practice terminal**. It's pretend, so nothing you type there can hurt your Mac.

Every Terminal is always "standing" in one folder, called the **current directory**. The command `pwd` (print working directory) tells you where you are.

## Step: teach
Now the real thing. **Homebrew** is a *package manager*: you ask for a tool by name, and it downloads it, installs it and keeps it up to date. Almost every developer on a Mac uses it.

You'll install it with one long command from Homebrew's official site, brew.sh. It will ask for your Mac password. When you type it, **nothing appears on screen**, not even dots. That's normal. Type it and press Return.

## Step: mac
Open your real Terminal. Copy this whole line exactly, paste it and press Return. It takes a few minutes. When it finishes, paste the last 10 or so lines of what it printed.

### Run
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### Checks
| type | call / input | expected |
|---|---|---|
| output_matches | - | `(?i)(installation successful\|already installed\|next steps)` |

### Hints
1. If it asks "Press RETURN to continue", press Return. If it asks for your password, type it blind and press Return.
2. If it says Homebrew is already installed, that's fine. Paste that message.
3. If you see a red error, paste the whole error. Don't guess. Reading errors is part of the job.

## Step: teach
On Apple Silicon Macs, Homebrew installs into `/opt/homebrew`, and your Terminal doesn't know to look there yet. The installer's "Next steps" told you to run two commands. They add one line to a settings file called `~/.zprofile`, which your Terminal reads every time it opens.

Let's run them one at a time so you can see what each does.

## Step: mac
This adds Homebrew's setup line to your `~/.zprofile` file. It prints nothing if it works, so paste the output of the second command below instead.

### Run
```
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
```

```
tail -1 ~/.zprofile
```

### Checks
| type | call / input | expected |
|---|---|---|
| output_matches | - | `brew shellenv` |

### Hints
1. Run the first line, then the second. Paste only what `tail` prints.
2. `>>` means "add to the end of the file". A single `>` would wipe the file first, so look closely.
3. If `tail` shows nothing about brew, run the first line again exactly as written, quotes included.

## Step: mac
Now load that setting into the window you have open, then ask Homebrew for its version.

|---|---|---|

### Hints
1. If you get "command not found: brew", run the `eval` line first, then try again.
2. You can also close Terminal completely and open a new window. New windows read `~/.zprofile` on their own.

## Step: teach
Next comes Ruby. Ruby needs a few helper libraries to build, and Homebrew can install them all in one command. Then we'll install **mise**, the version manager.

Why a version manager? Real projects pin a Ruby version. Next year you might need two versions side by side, and mise switches between them for you.

## Step: mac
Install Ruby's helper libraries and mise with Homebrew. This takes a few minutes. Paste the last few lines.

### Run
```
brew install openssl@3 libyaml gmp rust mise
```

### Checks
| type | call / input | expected |
|---|---|---|
| output_matches | - | `(?i)(mise\|already installed\|pouring\|installed)` |

### Hints
1. The names are separated by single spaces. `openssl@3` has no spaces in it.
2. Warnings in yellow are usually fine. Errors in red are what we want to see. Paste them.

## Step: mac
Tell your shell to switch mise on in every new window, then reload your settings. Paste what the last command prints.

### Run
```
echo 'eval "$(mise activate zsh)"' >> ~/.zshrc
```

```
source ~/.zshrc
```

```
mise --version
```

### Checks
| type | call / input | expected |
|---|---|---|
| output_matches | - | `\d{4}\.\d+\.\d+` |

### Hints
1. Three commands, run one at a time, in order.
2. This file is `~/.zshrc`, with an "rc" ending, which is different from `~/.zprofile`. Both are settings files your shell reads.
3. If `mise` is not found, run `eval "$(/opt/homebrew/bin/brew shellenv)"` and try again.

## Step: mac
The big moment: install the latest Ruby and make it your default everywhere. Building Ruby can take 5 to 10 minutes. Let it run.

### Run
```
mise use --global ruby
```

### Checks
| type | call / input | expected |
|---|---|---|
| output_matches | - | `(?i)ruby` |

### Hints
1. `--global` means "use this Ruby in every folder unless a project says otherwise."
2. If it stops with an error that mentions openssl or yaml, paste the whole thing. It means one of the helper libraries didn't install.

## Step: mac
Prove it worked. Open a **new** Terminal window (Command + N) and run both commands. Paste both outputs.

### Run
```
ruby -v
```

```
which ruby
```

### Checks
| type | call / input | expected |
|---|---|---|
| output_matches | - | `ruby [3-9]\.\d+` |
| output_matches | - | `mise` |

### Hints
1. If it still says `ruby 2.6`, your new window hasn't loaded mise. Run `source ~/.zshrc` and try again.
2. `which ruby` should show a path containing `mise`, not `/usr/bin/ruby`. `/usr/bin` is Apple's copy.

## Study guide
- The Terminal always stands in one folder, the current directory. `pwd` prints it and `ls` lists it.
- `~` is shorthand for your home folder.
- Homebrew is a package manager: `brew install name` installs a tool.
- On Apple Silicon, Homebrew lives in `/opt/homebrew`. `~/.zprofile` tells new windows where to find it.
- mise is a version manager. `mise use --global ruby` sets your default Ruby.
- `~/.zshrc` and `~/.zprofile` are settings files your shell reads when a window opens.
- `>>` adds to the end of a file. `>` replaces the file. Never mix them up on a settings file.
- `which ruby` shows which Ruby runs. `/usr/bin/ruby` is Apple's, and a mise path is yours.

## Flashcards
- What does `pwd` print? :: The folder the Terminal is standing in (the working directory).
- What does `ls` do? :: Lists what's inside the current folder.
- What does `~` mean in a path? :: Your home folder.
- What is Homebrew? :: A package manager that installs and updates tools on your Mac.
- What does mise manage? :: Versions of languages like Ruby, so you can switch between them.
- `>>` vs `>` when writing to a file? :: `>>` appends to the end; `>` overwrites the whole file.
- Where does Homebrew live on Apple Silicon? :: `/opt/homebrew`
- How do you check which Ruby will run? :: `which ruby` (and `ruby -v` for the version).
