## Step: teach
The **Terminal** is a window where you type commands instead of clicking. You type a command, press Return, and the computer prints a response. Developers live in it because it's fast, exact and repeatable. A command you type today does the same thing tomorrow.

The program running inside the Terminal is called the **shell**. On your Mac it's **zsh**.

## Step: teach
In class you checked four things, with one command each:

| Command | What it told you |
|---|---|
| `sw_vers` | macOS 27.0.1 |
| `xcode-select -p` | Xcode's developer tools are installed |
| `git --version` | git 2.54.0 |
| `ruby -v` | Ruby 2.6.10, Apple's old built-in copy |

The pattern `tool --version` (or `tool -v`) works for almost every developer tool. It's the fastest way to ask "is this installed, and which one?"

## Step: teach
Then you ran your first program:

```
ruby -e 'puts "Hello, Ironwood!"'
```

- `ruby` starts the Ruby language.
- `-e` means "execute the code that follows, right here on this line".
- `puts "..."` is Ruby code that **prints** text and a new line ("put string").
- The single quotes around the Ruby code keep the shell from getting confused by the double quotes inside it.

## Step: try
mode: terminal
Use `ruby -e` to print `Hello, Ironwood!` in the practice terminal.

### Checks
| type | call / input | expected |
|---|---|---|
| command_matches | - | `^ruby\s+-e\s` |
| output_matches | - | `^Hello, Ironwood!$` |

### Hints
1. `ruby -e`, then the Ruby code in single quotes.
2. Inside the single quotes: `puts` and the text in double quotes.

## Step: quiz
What's wrong with this command?

```
ruby -e "puts "Hello, Ironwood!""
```
- [ ] `puts` is misspelled
- [x] The double quotes inside end the outer double quotes early, so the shell splits the code apart
- [ ] `-e` should be `-v`
> The shell pairs the first `"` with the next `"` it sees. Use single quotes outside and double quotes inside.

## Study guide
- The Terminal is a text window for commands, and the shell (zsh on your Mac) runs them.
- `tool --version` or `tool -v` checks whether a tool is installed and which version.
- Apple's Ruby 2.6 is too old for Rails 8. Never install gems into it.
- `ruby -e '...'` runs one line of Ruby code.
- `puts` prints text followed by a new line.
- Single quotes outside, double quotes inside, so the shell doesn't split your code.

## Flashcards
- What is the shell on your Mac called? :: zsh
- How do you check a tool's version? :: `tool --version` (often `tool -v`)
- What does `ruby -e` do? :: Runs the Ruby code written right after it on the same line.
- What does `puts` do? :: Prints text plus a new line.
- Why not use Apple's built-in Ruby? :: It's 2.6, too old for Rails 8, and macOS depends on it.
- How do you fix `ruby -e "puts "hi""`? :: Use single quotes outside: `ruby -e 'puts "hi"'`.
