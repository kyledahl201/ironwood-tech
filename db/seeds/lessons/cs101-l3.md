## Step: teach
So far every variable has held one value. Real programs deal with lists: every job on today's schedule, every line on an estimate, every user signed up this week.

Ruby's list is the **array**. Today you'll make arrays, pull items out of them, and then meet your first **loop**, `.each`, which runs the same code once for every item.

## Step: teach
An array is values in square brackets, separated by commas:

```ruby
jobs = ["roof", "gutters", "siding"]
```

Every item has a position called an **index**, and indexes start at **0**, not 1:

- `jobs[0]` is `"roof"`
- `jobs[1]` is `"gutters"`
- `jobs[-1]` is the last item, `"siding"`

## Step: teach
Arrays have methods too:

- `jobs.length` gives how many items (3)
- `jobs.first` and `jobs.last`
- `jobs << "windows"` adds an item to the end (say it "shovel")
- `jobs.include?("roof")` gives `true` or `false`

Methods ending in `?` answer a yes-or-no question.

## Step: teach
Now the loop. Say you want to print every job. You could write four `puts` lines, but what if there are 400 jobs? `.each` runs a block of code once per item:

```ruby
jobs.each do |job|
  puts "Scheduled: #{job}"
end
```

- `do ... end` is the **block**, the code to repeat.
- `|job|` is the block's variable. On each pass it points at the next item.

## Step: teach
Loops get powerful when they **build up** an answer. The pattern is called an **accumulator**:

1. Before the loop, set a variable to a starting value, like `count = 0`.
2. Inside the loop, update it on each pass.
3. After the loop, use it.

Remember from Lesson 1: `count = count + 1` reads the old value and stores a new one. Ruby has a shortcut, `count += 1`, that does the same thing.

## Step: quiz
What's wrong here?

```ruby
total = 0
[5, 5, 5].each do |n|
  total = 0
  total += n
end
puts total
```
- [ ] Nothing, it prints 15
- [x] `total` is reset to 0 on every pass, so it prints 5
- [ ] `+=` doesn't work on numbers
> The start value belongs before the loop. Inside the loop it wipes out the running total each time.

## Study guide
- Arrays hold ordered lists: `["a", "b"]`. Indexes start at 0, and `[-1]` is the last item.
- Reading past the end gives `nil`.
- `.length`, `.first`, `.last`, `<<` to add, and `.include?` to check.
- `array.each do |item| ... end` runs the block once per item.
- Accumulator: start before the loop, update inside, use after.
- `x += 1` is short for `x = x + 1`.
- Resetting the accumulator inside the loop is a classic bug.

## Flashcards
- What index is the first item in an array? :: `0`
- How do you get the last item? :: `array[-1]` or `array.last`
- What does `<<` do to an array? :: Adds an item to the end.
- What do methods ending in `?` return? :: `true` or `false`.
- In `jobs.each do |job|`, what is `job`? :: The block variable; it points at the current item on each pass.
- What are the three parts of an accumulator? :: Start value before the loop, update inside, use after.
- What is `x += 3` short for? :: `x = x + 3`
- What does `["a"][5]` give? :: `nil`
