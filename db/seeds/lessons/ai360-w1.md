## Step: teach
Most data you'll handle in this course comes as a **dictionary** (dict for short): labels paired with values. If you've met Ruby, it's the same idea as a hash.

```python
job = {"customer": "R. Okoye", "windows": 6, "rush": False}

```

The labels are called **keys**. Square brackets with a key read a value back out.

## Step: teach
Next, **functions**. A function is a named piece of work: values go in (the **arguments**), and one value comes back (the **return value**).

```python
def double(n):
    return n * 2
```

Two things differ from Ruby. The body is marked by **indentation** (4 spaces), not by `end`. And Python never returns automatically: if you forget `return`, the function hands back `None`.

## Step: teach
Python builds strings with **f-strings**: put an `f` before the quote, and anything inside `{ }` is evaluated.

```python
name = "Dana"
f"Hi, {name}!"    # 'Hi, Dana!'
```

You can put any expression inside the braces, including a dict lookup or a calculation.

## Step: teach
Now the format agents live on: **JSON** (JavaScript Object Notation). It's **text** that looks almost exactly like Python dicts and lists. Programs send it to each other because every language can read it.

Python's built-in `json` module translates both ways:
- `json.loads(text)` turns JSON text into Python dicts and lists ("load string").
- `json.dumps(value)` turns Python values into JSON text ("dump string").

## Step: teach
Last idea for today: an **API** (application programming interface) is a program that answers requests from other programs. You send a request to a URL, often with settings in the URL called **query parameters**, and it sends back a response: a **status code** (200 means OK) and a body, usually JSON.

```
https://api.example.com/forecast?lat=41.9&lon=-87.6
```

That's the whole trick behind every AI model you'll call in this course. You send JSON to a URL and JSON comes back. In the lab, you'll do it for real.

## Study guide
- A dict pairs keys with values: `d["key"]` reads, `d["key"] = v` writes or adds.
- `d["missing"]` raises `KeyError`; `d.get("missing")` returns `None`.
- `def name(args):` plus an indented body defines a function. Python returns `None` unless you write `return`.
- f-strings: `f"high {temp}F"` evaluates whatever is inside the braces.
- JSON is text. `json.loads` turns text into Python data, and `json.dumps` turns data into text.
- JSON `true`/`false`/`null` become Python `True`/`False`/`None`.
- An API is a URL you send a request to. It answers with a status code (200 = OK) and usually a JSON body.
- Show me the trace: look at the actual value before you trust your code.

## Flashcards
- How do you read a key that might be missing, without an error? :: `d.get("key")`, which returns `None` if it's missing.
- What does a Python function return if there's no `return` line? :: `None`
- What marks a function's body in Python? :: Indentation (4 spaces), not an `end` keyword.
- `json.loads` vs `json.dumps`? :: `loads`: JSON text to Python data. `dumps`: Python data to JSON text.
- What does JSON `null` become in Python? :: `None`
- What does status code 200 mean? :: The request succeeded.
- What's a query parameter? :: A setting added to a URL after `?`, like `?lat=41.9&lon=-87.6`.
- `round(0.3 * 100)`? :: `30` (without `round`, it's `30.000000000000004`).
