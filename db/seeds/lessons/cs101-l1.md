## Step: teach
Welcome to CS 101, Kyle. CS 090 gave you the tools. Now we learn to think in Ruby.

Today has three ideas. **Values** are the pieces of data a program works with. **Variables** are names you stick on values. **String interpolation** builds text out of values. You'll work in **irb**, Ruby's console: you type one line, press Enter, and Ruby shows you the value right away.

## Step: teach
Every value has a type. The three you'll use most today:

- **Integers**, whole numbers: `3`, `42`, `-7`
- **Floats**, numbers with a decimal point: `19.99`, `0.5`
- **Strings**, text in quotes: `"Kyle"`, `"window estimate"`

In irb, the line that starts with `=>` is the value of what you just typed. Watch that arrow. It is Ruby talking back to you.

## Step: teach
A **variable** is a name that points at a value. You create one with a single `=`:

```ruby
hours = 8
```

Read `=` as "now points at", not as "equals". `hours = 8` means "the name `hours` now points at 8". Variable names are lowercase, with underscores between words: `hourly_rate`, `job_count`.

## Step: teach
Here is the part that tripped you up on placement day. A variable can be **pointed somewhere else** later. That's called reassignment:

```ruby
hours = 8
hours = 10
```

After the second line, `hours` is 10. The 8 is gone. Ruby always reads top to bottom and uses whatever the name points at **right now**.

### Hints
1. Same shape as when you first made `hours`.
2. `rate` didn't change, so it is still 25.

## Step: teach
Now strings. You can glue strings with `+`, but there's a cleaner way called **interpolation**. Inside **double** quotes, `#{ }` drops any value into the text:

```ruby
name = "Kyle"
"Hi, #{name}!"   # => "Hi, Kyle!"
```

Anything can go in the braces, including math: `"Total: #{hours * rate}"`.

## Step: try

### Checks
| type | call / input | expected |
|---|---|---|
| command_matches | - | `^name\s*=\s*"[^"]+"$` |

### Hints
1. Strings need quotes.
2. Use double quotes, so you can interpolate it in the next step.

## Step: try
mode: irb
Using interpolation, build the string `Kyle works 10 hours` with your `name` and `hours` variables. Type no number and no name directly in the string.

### Checks
| type | call / input | expected |
|---|---|---|
| command_matches | - | `#\{name\}.*#\{hours\}` |

### Hints
1. Double quotes on the outside, and `#{ }` around each variable.
2. The words "works" and "hours" are plain text. Only the name and the number come from variables.

## Step: quiz
What does `'Hi, #{name}'` (single quotes) give you?
- [ ] "Hi, Kyle"
- [x] The text `Hi, #{name}` exactly as typed

> Interpolation only works inside double quotes.

## Step: teach
A last tool for today: strings have **methods**, actions you call with a dot.

- `"kyle".upcase` gives `"KYLE"`
- `"Kyle".length` gives `4`
- `"  hi  ".strip` gives `"hi"`

You'll meet hundreds of these. You don't memorize them. You learn to look them up and try them in irb.

## Study guide
- Values have types: Integer (`3`), Float (`19.99`) and String (`"text"`). `.class` tells you which.
- Integer divided by integer drops the remainder: `7 / 2` is `3`.
- `=` means "now points at". `hours = 8` names the value 8.
- Reassignment points a name at a new value. Ruby uses the latest one.
- `total = total + 3` reads the old value, adds, and stores the new one.
- `"#{expr}"` interpolates any value into a double-quoted string. Single quotes don't interpolate.
- Methods are called with a dot: `.upcase`, `.length`, `.strip`.

## Flashcards
- How do you find a value's type? :: Call `.class` on it, e.g. `42.class`.
- What is `7 / 2` in Ruby? :: `3` (integer division drops the remainder).
- How should you read `x = 5`? :: "x now points at 5."
- What naming style do Ruby variables use? :: lowercase with underscores (snake_case), e.g. `job_count`.
- `x = 2`, then `x = x * 5`. What is x? :: `10`
- What does `"Hi, #{name}"` do? :: Puts the value of `name` into the string (interpolation).
- Do single quotes interpolate? :: No. Only double quotes do.
- How do you get a string's length? :: `.length` (or `.size`).
