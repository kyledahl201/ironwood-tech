## Step: teach
Your programs so far do the same thing every time. Today they start making **decisions**.

You'll learn to compare values, which gives you `true` or `false`, and to use `if` and `else` to run different code depending on the answer. Then you'll put an `if` inside a loop, which is where it gets genuinely useful.

## Step: teach
Comparison operators ask a question and answer `true` or `false`:

| Operator | Means |
|---|---|
| `==` | is equal to |
| `!=` | is not equal to |
| `>` / `<` | greater / less than |
| `>=` / `<=` | greater or equal / less or equal |

Careful: `==` (two signs) **compares**. `=` (one sign) **assigns**. Mixing them up is a classic bug.

## Step: teach
Now `if`. The code inside runs only when the condition is true:

```ruby
if amount > 1000
  puts "Needs manager approval"
end
```

Add `else` for what to do otherwise, and `elsif` (spelled exactly like that) for more choices:

```ruby
if amount > 5000
  "large"
elsif amount > 1000
  "medium"
else
  "small"
end
```

Ruby checks top to bottom and runs the **first** branch that's true, then skips the rest.

## Step: teach
Two ways to combine conditions:

- `&&` means **and**: both must be true. `amount > 1000 && status == "booked"`
- `||` means **or**: at least one must be true. `day == "Sat" || day == "Sun"`

## Step: teach
Now the payoff: an `if` **inside a loop**. The loop visits every item, and the `if` decides what to do with each one:

```ruby
amounts.each do |amount|
  if amount > 1000
    puts "Review: #{amount}"
  end
end
```

Combine that with last lesson's accumulator and you can count or total only the items that match.

## Study guide
- `==`, `!=`, `>`, `<`, `>=`, `<=` compare values and return `true` or `false`.
- `=` assigns and `==` compares. Never use `=` in a condition.
- `if ... elsif ... else ... end` runs the first true branch only, so put the strictest check first.
- An `if` has a value, the value of the branch that ran, so a method can end with one.
- `&&` is "and" (both true) and `||` is "or" (at least one true).
- An `if` inside `.each` lets a loop act on only some items. Add a counter to count matches.

## Flashcards
- What's the difference between `=` and `==`? :: `=` assigns a value; `==` compares two values.
- What does `!=` mean? :: Not equal to.
- How many branches of an if/elsif/else can run? :: At most one: the first that's true.
- What does `&&` mean? :: And. Both sides must be true.
- What does `||` mean? :: Or. At least one side must be true.
- Is `"A" == "a"` true? :: No. Comparisons are case-sensitive.
- How do you count matching items in a loop? :: Counter before the loop, increase it inside an `if`, use it after.
- What does a method ending in `?` usually return? :: `true` or `false`.
